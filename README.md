# C# Garage Management System

A garage management system developed as part of a Computer Science course.

The project demonstrates object-oriented programming principles and a multi-project architecture, with a separation between the garage logic and console user interface.

## Features

- Vehicle management
- Support for different vehicle types
- Fuel and electric vehicles
- Vehicle status management
- License type and vehicle-specific properties
- Custom exceptions
- Collections and polymorphism
- File-based vehicle data
- Separation between business logic and user interface

## Project Structure

- `Ex03.GarageLogic` – Core garage logic, vehicle classes, enums, and business rules
- `Ex03.ConsoleUI` – Console-based user interface and application flow

## Technologies

- C#
- .NET
- Object-Oriented Programming
- Collections
- Inheritance
- Polymorphism
- Custom Exceptions
- File I/O

## Academic Context

This project was developed as part of a C# course in the B.Sc. Computer Science program at the Academic College of Tel Aviv-Yaffo.
